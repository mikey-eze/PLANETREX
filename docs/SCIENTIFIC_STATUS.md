# PLANETREX scientific status

This is a prototype implementation from the uploaded Moon-First Explorer project. The current GitHub migration is incomplete compared with the original 89-file archive.

Current:
- Documented mission-site coordinates for navigation.
- FastAPI backend routes for Earth events (EONET), PDS catalog metadata, geographic cells and saved profiles.
- Manual developer profile import with distinct Earth/Moon/Mars coordinate declarations.
- Preliminary terrain comparison based on normalized differences, *not* calibrated similarity percentages.
- A lightweight Moon-first browser explorer using schematic planetary shading and labeled markers.

Not present or verified:
- Full eight-category planetary data ingestion
- Scientifically calibrated similarity percentages
- Validated worldwide discoveries
- Georegistered lunar or Martian imagery
- Full original React frontend and binary planet textures
- Public web deployment or visual browser verification

Do not present these features as scientifically proven. The original uploaded ZIP remains the reference for the complete project source.
